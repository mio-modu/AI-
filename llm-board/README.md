# LLM 보드

Claude · GPT · Gemini를 **한 화면에서 쓰면서, 메시지마다 드는 비용을 원화로 바로 보는** 개인용 보드입니다.
구독이 아니라 API 종량제로 쓰기 위해 만들었습니다.

## 먼저 알아야 할 것 — 이게 항상 싸지는 않습니다

**용도에 따라 결론이 정반대입니다.**

| 용도 | 결론 |
| --- | --- |
| 채팅 · 글쓰기 · 질의응답 | **API가 훨씬 쌉니다.** 이 보드를 쓰세요 |
| 코딩 에이전트 (Claude Code 등) | **구독이 훨씬 쌉니다.** 바꾸면 몇 배 더 나갑니다 |

코딩 에이전트는 매 턴 파일 내용과 툴 결과를 통째로 보내서 토큰 소모가 채팅의 수십 배입니다.
구독은 정액이라 그 사용량을 흡수하지만, API는 쓴 만큼 그대로 청구됩니다.

### 월 15만원이면 몇 턴까지 이득인가

한 턴당 입력 3,000 / 출력 800 토큰(일반적인 채팅) 기준, 환율 1,450원:

| 모델 | 턴당 비용 | 15만원이면 |
| --- | --- | --- |
| Claude Haiku 5.5 | 1.0원 | **147,783턴** |
| Claude Sonnet 5.5 | 20.3원 | **7,389턴** |
| Claude Opus 5.5 | 40.6원 | **3,694턴** |

하루 30턴을 쓴다면 Sonnet으로 **월 1.8만원** 수준입니다.
`npm test`를 돌리면 이 표를 직접 계산해서 보여줍니다.

## 쓰는 법

```bash
npm install
cp .env.example .env.local   # 쓸 제공사의 키만 채우면 됩니다
npm run dev
```

키는 **서버에서만** 쓰이고 브라우저로 내려가지 않습니다.
키를 안 넣은 제공사는 선택해도 안내 메시지가 나옵니다.

### OpenAI 호환 서버로 더 싸게

`OPENAI_BASE_URL`을 바꾸면 OpenRouter나 로컬 모델 같은 OpenAI 호환 엔드포인트로 돌릴 수 있습니다.

```
OPENAI_BASE_URL=https://openrouter.ai/api/v1
```

## 비용이 보이는 방식

- **메시지마다** 입력/출력 토큰과 원화 금액을 바로 표시합니다.
- **이번 달 누적**과 구독료 대비 절약액을 상단에 띄웁니다. 구독료는 직접 고칠 수 있습니다.
- 토큰 수는 각 API가 돌려주는 **실제 값**입니다. 틀릴 수 있는 건 단가뿐입니다.
- 그래서 기록에는 **금액이 아니라 토큰 수와 모델 ID만** 저장합니다.
  요금표를 고치면 과거 기록까지 자동으로 다시 계산됩니다.

### 요금표는 직접 확인하세요

`src/lib/pricing.ts`에 모델별 단가가 있고, 항목마다 신뢰도를 달아뒀습니다.

- **Claude** — Anthropic 공식 요금 기준 (`요금 확인됨`)
- **GPT · Gemini** — 3자 집계 기준이라 `요금 미확인`으로 표시됩니다.
  공식 요금 페이지와 대조한 뒤 이 파일을 고치세요.

보드 화면에도 모델마다 확인 여부 배지가 뜹니다.

## 검증한 것 / 못 한 것

```bash
npm test        # 요금 계산 17건 + 스트림 파싱 34건
```

**검증함**
- 요금 계산 — 손계산과 대조, 환율 반영, 0원 뭉개짐 방지
- SSE 파싱 — 청크가 줄 중간에서 끊겨도 복구
- 토큰 집계 — Anthropic 캐시 토큰, Gemini 사고 토큰을 빠뜨리지 않고 합산
- 요청 본문 — 스트리밍·사용량 수신 옵션 등 비용에 직결되는 필드
- **전 구간 스트리밍** — OpenAI 호환 모의 서버로 라우트→파싱→화면 확인
- UI — 턴별 비용, 월 누적, 절약액 표시, 모바일 레이아웃

**못 함**
- **실제 제공사 API 라이브 호출.** 개발 환경에 쓸 수 있는 키가 없었습니다.
  모의 서버로 OpenAI 호환 경로는 확인했지만, **Anthropic SDK 경로와 Gemini 실제 응답은 미검증**입니다.
  키를 넣고 각 모델로 한 번씩 보내보는 것이 첫 할 일입니다.
- 모델 ID는 바뀔 수 있습니다. 404가 나면 `src/lib/pricing.ts`의 `id`를 고치세요.

## 제약

- 사용 기록은 **브라우저 localStorage**에 쌓입니다. 기기별로 따로 집계되고,
  시크릿 모드나 저장소 차단 시에는 기록이 남지 않습니다.
- 대화 내용은 저장하지 않습니다. 새로고침하면 사라집니다.
- 이미지·파일 첨부는 아직 없습니다. 텍스트 대화만 됩니다.
