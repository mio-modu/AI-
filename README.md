# 착용컷 생성기 (ModelCut)

상품 사진 한 장으로 커머스용 **모델 착용컷**을 만들어 주는 웹앱입니다.
스튜디오 섭외 · 모델 섭외 · 촬영 · 보정 없이 상세페이지 메인컷을 뽑는 것이 목표입니다.

## 무엇을 해결하나

이커머스 셀러가 신상품 하나를 올릴 때마다 겪는 비용은 대체로 이렇습니다.

| 항목 | 기존 외주 촬영 | 착용컷 생성기 |
| --- | --- | --- |
| 모델 · 스튜디오 | 건당 수십만 원 | 없음 |
| 소요 시간 | 섭외부터 납품까지 수일 | 약 12초 ~ 1분 |
| 재촬영 | 추가 비용 · 일정 재조율 | 프리셋만 바꿔 즉시 재생성 |
| 비율 변형 (상세 / 썸네일 / 릴스) | 별도 리터칭 | 비율 선택으로 바로 출력 |

## 핵심 설계

**셀러는 영어 프롬프트를 쓸 줄 모른다**는 전제로 만들었습니다.
UI에서는 한국어 프리셋만 고르고, 실제 모델에 들어가는 영문 지시문은
`src/lib/presets.ts` + `src/lib/prompt.ts`가 합성합니다.

- **상품 재현 우선** — 프롬프트 최상단에 "레퍼런스의 색상 · 원단 · 프린트 · 봉제를 그대로 재현하고
  재디자인하지 말 것"을 절대 제약으로 고정했습니다. 착용컷의 성패는 여기서 갈립니다.
- **자동 코디** — 카테고리별로 함께 입힐 옷을 무채색 베이직으로 고정합니다.
  상의를 팔면 하의가, 하의를 팔면 상의가 시선을 뺏지 않아야 합니다.
- **카테고리별 프레이밍** — 신발은 로우앵글, 하의는 허리~발밑, 원피스는 전신처럼
  카테고리마다 컷 구성이 달라집니다.
- **구조 고정** — 프롬프트 섹션 순서와 라벨을 항상 동일하게 유지해서
  같은 설정의 결과 편차를 줄이고, 어떤 항목이 결과를 바꿨는지 추적할 수 있게 했습니다.

## 프리셋

| 구분 | 항목 |
| --- | --- |
| 카테고리 | 상의 · 아우터 · 원피스 · 하의 · 신발 · 가방 · 액세서리 |
| 모델 | 20·30대 한국 여성 / 55~66 / 20·30대 한국 남성 / 5060 여성 / 아동 / 글로벌 |
| 배경 | 화이트 · 웜그레이 · 베이지 스튜디오 / 도심 · 카페 · 홈 · 자연 · 리조트 · 오피스 |
| 포즈 | 정면 전신 · 3/4 전신 · 상반신 · 디테일 · 워킹 · 앉은 자세 · 뒷모습 |
| 비율 | 4:5 · 1:1 · 3:4 · 2:3 · 9:16 · 16:9 |

비율은 채널에 맞춰 뽑도록 했습니다 — 4:5는 상세페이지 · 인스타 피드,
3:4는 네이버 스마트스토어, 9:16은 릴스 · 숏폼입니다.

## 품질 티어

| 티어 | 모델 | 해상도 | 용도 |
| --- | --- | --- | --- |
| 빠름 | `gemini-3.1-flash-image` (Nano Banana 2) | 1K · 2K | 대량 생성 · 후보컷 |
| 고품질 | `gemini-3-pro-image` (Nano Banana Pro) | 1K · 2K · 4K | 메인컷 · 인쇄 · 확대컷 |

여러 장을 뽑아 고르는 방식이 결과가 가장 좋아서, 한 번에 최대 4장까지 병렬 생성합니다.
일부 컷이 실패해도 성공한 컷은 그대로 돌려줍니다.

## 실행

```bash
npm install
cp .env.example .env.local   # GEMINI_API_KEY 입력
npm run dev
```

API 키는 [Google AI Studio](https://aistudio.google.com/apikey)에서 발급합니다.
키는 서버에서만 쓰이고 브라우저로 내려가지 않습니다.

```bash
npm run build       # 프로덕션 빌드
npm run typecheck   # 타입 검사
```

## 배포 시 주의

생성 요청은 **길게 걸립니다.** 실측 기준으로 빠름 1K 2장이 약 12초, 고품질 9:16 1K가 약 19초,
고품질 4K는 28초를 넘어갑니다. 서버리스에 올릴 때 함수 실행 시간 제한을 반드시 확인하세요.

- `src/app/api/generate/route.ts`의 `maxDuration = 300`은 Vercel 기준 설정입니다.
  Hobby 플랜은 상한이 짧아 고품질 4K에서 잘립니다. 고품질 티어를 쓸 계획이면 Pro 플랜이 필요합니다.
- 앱 자체도 280초에서 요청을 끊고 안내 문구를 돌려줍니다. 플랫폼이 함수를 죽이면
  원인을 알 수 없는 에러만 남기 때문에, 그 전에 직접 끊는 편이 낫습니다.
- `GEMINI_API_KEY`는 서버 환경변수로만 설정하세요. `NEXT_PUBLIC_` 접두사를 붙이면 브라우저로 노출됩니다.

## 구조

```
src/
├─ app/
│  ├─ page.tsx                 설정 패널 + 결과 패널
│  ├─ layout.tsx
│  ├─ globals.css              디자인 토큰 (라이트 / 다크)
│  └─ api/generate/route.ts    생성 API · 검증 · 병렬 실행
├─ components/
│  ├─ Uploader.tsx             드래그앤드롭 업로드 (최대 3장 · 장당 7MB)
│  ├─ OptionGrid.tsx           프리셋 선택 UI
│  └─ ResultGallery.tsx        결과 · 다운로드 · 프롬프트 공개
└─ lib/
   ├─ presets.ts               프리셋 정의 (한국어 라벨 ↔ 영문 지시문)
   ├─ prompt.ts                프롬프트 합성 엔진
   └─ gemini.ts                Gemini 이미지 API 래퍼
```

## 알려진 제약

- 로고 · 브랜드 워드마크가 큼직하게 박힌 상품은 글자가 뭉개질 수 있습니다. 고품질 티어를 쓰거나
  로고가 작게 나오는 컷(워킹 · 3/4)으로 우회하세요.
- 복잡한 패턴(체크 · 레터링 그래픽)은 반복 간격이 미세하게 달라질 수 있습니다.
  상세페이지 메인컷은 생성컷, 원단 확대컷은 실사를 쓰는 조합을 권장합니다.
- 생성 이미지는 실제 착용 핏을 보증하지 않습니다. 실측 사이즈 표기는 별도로 유지하세요.
